# 人形机器人六维力传感器专题：需求增长与降价并行，上市公司兑现取决于客户突破

> **本作品由本人（邓兴华）独立完成**：选题、资料检索、需求与估值模型搭建、数据底稿整理、图表制作和全文写作均为个人完成，仅作为个人研究作品展示，不代表任何机构观点。

## 研究内容

围绕国内人形机器人末端六维力传感器，回答三个问题：

1. **市场有多大？** 按"整机出货 × 搭载率 × 单机用量 × 单价"测算，2030 年中国市场基准约 42 亿元（悲观 11 亿元，乐观 73 亿元）；与 GGII、赛迪预测的分歧主要来自每台平均用量。
2. **供应商能否受益？** 2025 年前三名份额合计 92.8%，均未上市；价值量高不等于上市公司利润高。
3. **上市公司能兑现多少？** 以柯力传感、安培龙、东华测试为样本，从行业规模推导公司收入和利润，并反推当前市值隐含的 2030 年份额（柯力约 25%，本文基准 8%）。

## 方法与口径

- 需求、收入、估值共用模型"假设"页的同一套参数；黄色底色为作者假设。
- 数据底稿区分实际、计划、测算、传闻，公司未披露的数据写"未披露"，不做推算。
- 估值反推：市值 − 原有业务价值 − 非经营性投资资产 → 折现 → ÷ 前瞻 PE → 所需利润和份额。

## 局限

- 三家公司均未单独披露六维力收入，公司份额为作者假设区间。
- 部分第三方数据（如赛迪、MIR）仅见于媒体转述，已在底稿中标注可信度。
- 市值为 2026-10-19 收盘口径，数据截止 2026-10-19。
